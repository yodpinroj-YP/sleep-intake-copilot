## ก่อนถ่ายทุกครั้ง

- กด `Ctrl` + `+` สองสามครั้งให้ตัวหนังสือใหญ่ขึ้น (กด `Ctrl` + `0` เพื่อกลับปกติ)
- ถ่ายเฉพาะการ์ดหรือส่วนที่ต้องการ ไม่ต้องเอาทั้งหน้าจอ
- ระวังชื่อกับอีเมลจริงติดมาในภาพ — เปลี่ยนชื่อใน `profiles` เป็นชื่อสมมุติก่อนถ่ายได้
- ใช้โหมดสีเดียวกันทุกภาพ อย่าสลับสว่าง/มืด
